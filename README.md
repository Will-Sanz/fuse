# Fuse

Senior Design team repository.

## Project direction

Fuse explores a persistent workspace for collaborating with AI agents, with editable GitHub, Linear, and Slack surfaces alongside the development workflow. This repository is the starting point for implementation; the existing concept demo is illustrative, and working integrations have not been built here yet.

## Get started

1. Accept your GitHub repository invitation and sign in to GitHub.
2. Clone this repository with GitHub Desktop or Git:

   ```sh
   git clone https://github.com/Will-Sanz/fuse.git
   cd fuse
   ```

3. Read [CONTRIBUTING.md](CONTRIBUTING.md) before making your first change.

The application stack and development commands are still to be decided. Add installation, run, and test instructions here with the first working prototype.

## Working together

- Track tasks and bugs in [Issues](https://github.com/Will-Sanz/fuse/issues); agree on an owner before starting.
- Make changes on a branch and open a pull request for a teammate to review.
- Keep `main` usable and keep each pull request focused on one task.
- Store credentials in local environment files, never in Git.

## First milestone

Agree on the smallest useful demo, choose the application stack, and build one complete interaction before expanding to additional integrations.
